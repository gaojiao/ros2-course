# 14.URDF文件

URDF（Unified Robot Description Format，统一机器人描述格式）是ROS中用于描述机器人几何结构、运动学和动力学属性的XML格式文件。通过URDF，我们可以定义一个机器人的连杆（link）、关节（joint）以及它们之间的连接关系，从而在仿真、可视化、运动规划等场景中统一表示机器人模型。本章将介绍URDF的基本语法，并通过实例创建一个完整的机器人模型，然后在ROS 2中加载、可视化，并简要说明如何在Gazebo仿真中使用。

可参考ROS 2官方`URDF`文档： https://docs.ros.org/en/rolling/Tutorials/Intermediate/URDF/URDF-Main.html

## 14.1 URDF概述

URDF文件以`.urdf`为扩展名，采用XML语法。一个URDF模型通常包含以下部分：

- **机器人名称**：`<robot name="my_robot">` 根标签。
- **连杆（link）**：描述机器人的刚性部件，每个link有质量、惯性、视觉形状、碰撞形状等属性。
- **关节（joint）**：描述两个link之间的连接关系，包括关节类型（固定、旋转、移动等）、位置限制、动力学参数等。
- **传感器、执行器等**：可选，可通过插件扩展。

URDF的核心是建立一棵以`base_link`为根的连杆-关节树，所有其他link通过关节连接到根link上。

在ROS 2中，URDF文件通常放置在功能包的`urdf`或`description`文件夹中，并通过`robot_state_publisher`节点发布机器人状态（即各关节角度对应的TF变换）。

## 14.2 URDF基本元素

### 14.2.1 `<robot>` 标签

`<robot>`是根标签，包含`name`属性，以及所有`<link>`和`<joint>`子标签。

```xml
<robot name="my_robot">
    <!-- links and joints -->
</robot>
```

### 14.2.2 `<link>` 标签

每个`<link>`定义一个机器人部件，包含视觉、碰撞、惯性等可选子标签。

```xml
<link name="base_link">
    <visual>
        <geometry>
            <box size="0.4 0.2 0.1"/>   <!-- 长方体，单位米 -->
        </geometry>
        <origin xyz="0 0 0" rpy="0 0 0"/> <!-- 相对于link原点的位姿 -->
        <material name="blue"/>
    </visual>
    <collision>
        <geometry>
            <box size="0.4 0.2 0.1"/>
        </geometry>
        <origin xyz="0 0 0" rpy="0 0 0"/>
    </collision>
    <inertial>
        <mass value="1.0"/>
        <inertia ixx="0.1" ixy="0" ixz="0" iyy="0.1" iyz="0" izz="0.1"/>
        <origin xyz="0 0 0" rpy="0 0 0"/>
    </inertial>
</link>
```

常用的几何形状：
- `<box size="x y z"/>`
- `<sphere radius="r"/>`
- `<cylinder radius="r" length="l"/>`
- `<mesh filename="package://my_pkg/meshes/my_mesh.dae"/>` 导入外部网格文件

材质`<material>`可以定义颜色或纹理，例如：
```xml
<material name="blue">
    <color rgba="0 0 1 1"/>
</material>
```

### 14.2.3 `<joint>` 标签

`<joint>`定义两个连杆之间的连接，包括类型、父子关系、位姿、限制等。

```xml
<joint name="left_wheel_joint" type="continuous">
    <parent link="base_link"/>
    <child link="left_wheel"/>
    <origin xyz="0.2 -0.15 0" rpy="0 0 0"/>
    <axis xyz="0 1 0"/>   <!-- 旋转轴 -->
    <limit effort="10" velocity="5"/> <!-- 连续关节无位置限制 -->
</joint>
```

关节类型（`type`）：
- **fixed**：固定连接，无相对运动。
- **revolute**：旋转关节，有角度限制（需指定`<limit lower="..." upper="..."/>`）。
- **continuous**：连续旋转关节，无角度限制（如轮子）。
- **prismatic**：移动关节，线性运动（需指定`<limit lower="..." upper="..."/>`）。
- **planar**：平面运动关节。
- **floating**：六自由度浮动关节。

### 14.2.4 坐标系与原点

`<origin>`标签用于指定link相对于父坐标系的位置和姿态，或joint相对于父link的位置。`xyz`是平移（米），`rpy`是欧拉角（弧度，顺序为绕固定轴：滚转-俯仰-偏航）。

## 14.3 创建一个简单的两轮差速机器人模型

下面我们创建一个简单两轮差速机器人的URDF模型，包含：底盘（base_link）、两个驱动轮（left_wheel, right_wheel）和一个万向轮（caster_wheel）。所有关节均为旋转关节，驱动轮为连续型，万向轮为固定型。

创建文件 `my_robot.urdf` 在功能包的`urdf`目录下：

```xml
<?xml version="1.0"?>
<robot name="diff_drive_robot">
    <!-- 底盘 -->
    <link name="base_link">
        <visual>
            <geometry>
                <box size="0.5 0.4 0.2"/>
            </geometry>
            <origin xyz="0 0 0" rpy="0 0 0"/>
            <material name="gray">
                <color rgba="0.5 0.5 0.5 1"/>
            </material>
        </visual>
        <collision>
            <geometry>
                <box size="0.5 0.4 0.2"/>
            </geometry>
            <origin xyz="0 0 0" rpy="0 0 0"/>
        </collision>
        <inertial>
            <mass value="2.0"/>
            <inertia ixx="0.05" ixy="0" ixz="0" iyy="0.05" iyz="0" izz="0.05"/>
            <origin xyz="0 0 0" rpy="0 0 0"/>
        </inertial>
    </link>

    <!-- 左轮 -->
    <link name="left_wheel">
        <visual>
            <geometry>
                <cylinder radius="0.1" length="0.05"/>
            </geometry>
            <origin xyz="0 0 0" rpy="1.5708 0 0"/> <!-- 圆柱体默认轴线为Z，需旋转使其绕Y轴 -->
            <material name="black">
                <color rgba="0 0 0 1"/>
            </material>
        </visual>
        <collision>
            <geometry>
                <cylinder radius="0.1" length="0.05"/>
            </geometry>
            <origin xyz="0 0 0" rpy="1.5708 0 0"/>
        </collision>
        <inertial>
            <mass value="0.2"/>
            <inertia ixx="0.0001" ixy="0" ixz="0" iyy="0.0001" iyz="0" izz="0.0001"/>
        </inertial>
    </link>

    <joint name="left_wheel_joint" type="continuous">
        <parent link="base_link"/>
        <child link="left_wheel"/>
        <origin xyz="0 -0.2 -0.05" rpy="0 0 0"/>
        <axis xyz="0 1 0"/> <!-- 绕Y轴旋转 -->
    </joint>

    <!-- 右轮 -->
    <link name="right_wheel">
        <visual>
            <geometry>
                <cylinder radius="0.1" length="0.05"/>
            </geometry>
            <origin xyz="0 0 0" rpy="1.5708 0 0"/>
            <material name="black"/>
        </visual>
        <collision>
            <geometry>
                <cylinder radius="0.1" length="0.05"/>
            </geometry>
            <origin xyz="0 0 0" rpy="1.5708 0 0"/>
        </collision>
        <inertial>
            <mass value="0.2"/>
            <inertia ixx="0.0001" ixy="0" ixz="0" iyy="0.0001" iyz="0" izz="0.0001"/>
        </inertial>
    </link>

    <joint name="right_wheel_joint" type="continuous">
        <parent link="base_link"/>
        <child link="right_wheel"/>
        <origin xyz="0 0.2 -0.05" rpy="0 0 0"/>
        <axis xyz="0 1 0"/>
    </joint>

    <!-- 万向轮（支撑轮） -->
    <link name="caster_wheel">
        <visual>
            <geometry>
                <sphere radius="0.05"/>
            </geometry>
            <material name="gray"/>
        </visual>
        <collision>
            <geometry>
                <sphere radius="0.05"/>
            </geometry>
        </collision>
        <inertial>
            <mass value="0.05"/>
            <inertia ixx="0.00001" ixy="0" ixz="0" iyy="0.00001" iyz="0" izz="0.00001"/>
        </inertial>
    </link>

    <joint name="caster_wheel_joint" type="fixed">
        <parent link="base_link"/>
        <child link="caster_wheel"/>
        <origin xyz="-0.25 0 -0.1" rpy="0 0 0"/>
    </joint>
</robot>
```

## 14.4 在ROS 2中加载和可视化URDF

### 14.4.1 创建功能包并放置URDF文件

首先创建功能包（如果还没有），并创建`urdf`目录：

```bash
cd ~/ros2_ws/src
ros2 pkg create my_robot_description --build-type ament_python
cd my_robot_description
mkdir urdf
# 将上面的my_robot.urdf文件放入urdf目录
```

### 14.4.2 URDF可视化

使用`urdf_tutorial`功能包中的工具预览，将其中的`<用户名>`替换为自己的用户名：

```bash
ros2 launch urdf_tutorial display.launch.py model:=/home/<用户名>/ros2_ws/src/my_robot_description/urdf/my_robot.urdf
```

## 14.5 使用xacro简化URDF

随着机器人模型复杂化，URDF文件会变得冗长且难以维护。xacro（XML宏语言）提供了宏定义、常量、条件判断等功能，可以大大简化URDF编写。xacro文件通常以`.xacro`为扩展名，在构建时或运行时被处理成标准的URDF。

### 14.5.1 安装xacro

xacro是ROS 2的一部分，通常已安装。如果未安装，可执行：

```bash
sudo apt install ros-${ROS_DISTRO}-xacro
```

### 14.5.2 使用xacro改进机器人模型

下面将之前的URDF改写为xacro文件，使用常量定义颜色、尺寸等。

创建 `urdf/my_robot.xacro`：

```xml
<?xml version="1.0"?>
<robot name="diff_drive_robot" xmlns:xacro="http://www.ros.org/wiki/xacro">
    <!-- 定义常量 -->
    <xacro:property name="base_width" value="0.4"/>
    <xacro:property name="base_length" value="0.5"/>
    <xacro:property name="base_height" value="0.2"/>
    <xacro:property name="wheel_radius" value="0.1"/>
    <xacro:property name="wheel_width" value="0.05"/>
    <xacro:property name="wheel_offset_y" value="0.2"/>
    <xacro:property name="caster_radius" value="0.05"/>
    <xacro:property name="caster_x_offset" value="-0.25"/>
    <xacro:property name="caster_z_offset" value="-0.1"/>
    
    <!-- 材质 -->
    <xacro:property name="gray_material">
        <material name="gray">
            <color rgba="0.5 0.5 0.5 1"/>
        </material>
    </xacro:property>
    <xacro:property name="black_material">
        <material name="black">
            <color rgba="0 0 0 1"/>
        </material>
    </xacro:property>

    <!-- 宏：定义一个轮子 -->
    <xacro:macro name="wheel" params="name side">
        <link name="${name}">
            <visual>
                <geometry>
                    <cylinder radius="${wheel_radius}" length="${wheel_width}"/>
                </geometry>
                <origin xyz="0 0 0" rpy="${pi/2} 0 0"/>
                <xacro:insert_block name="black_material"/>
            </visual>
            <collision>
                <geometry>
                    <cylinder radius="${wheel_radius}" length="${wheel_width}"/>
                </geometry>
                <origin xyz="0 0 0" rpy="${pi/2} 0 0"/>
            </collision>
            <inertial>
                <mass value="0.2"/>
                <inertia ixx="0.0001" ixy="0" ixz="0" iyy="0.0001" iyz="0" izz="0.0001"/>
            </inertial>
        </link>
        
        <joint name="${name}_joint" type="continuous">
            <parent link="base_link"/>
            <child link="${name}"/>
            <origin xyz="0 ${side * wheel_offset_y} ${-wheel_radius}" rpy="0 0 0"/>
            <axis xyz="0 1 0"/>
        </joint>
    </xacro:macro>

    <!-- 底盘 -->
    <link name="base_link">
        <visual>
            <geometry>
                <box size="${base_length} ${base_width} ${base_height}"/>
            </geometry>
            <xacro:insert_block name="gray_material"/>
        </visual>
        <collision>
            <geometry>
                <box size="${base_length} ${base_width} ${base_height}"/>
            </geometry>
        </collision>
        <inertial>
            <mass value="2.0"/>
            <inertia ixx="0.05" ixy="0" ixz="0" iyy="0.05" iyz="0" izz="0.05"/>
        </inertial>
    </link>

    <!-- 使用宏创建左右轮 -->
    <xacro:wheel name="left_wheel" side="-1"/>
    <xacro:wheel name="right_wheel" side="1"/>

    <!-- 万向轮 -->
    <link name="caster_wheel">
        <visual>
            <geometry>
                <sphere radius="${caster_radius}"/>
            </geometry>
            <xacro:insert_block name="gray_material"/>
        </visual>
        <collision>
            <geometry>
                <sphere radius="${caster_radius}"/>
            </geometry>
        </collision>
        <inertial>
            <mass value="0.05"/>
            <inertia ixx="0.00001" ixy="0" ixz="0" iyy="0.00001" iyz="0" izz="0.00001"/>
        </inertial>
    </link>

    <joint name="caster_wheel_joint" type="fixed">
        <parent link="base_link"/>
        <child link="caster_wheel"/>
        <origin xyz="${caster_x_offset} 0 ${caster_z_offset}" rpy="0 0 0"/>
    </joint>
</robot>
```

注意：xacro支持数学表达式，如`${pi/2}`，需要确保xacro解析器能识别。使用`${pi}`需在文件顶部定义`<xacro:property name="pi" value="3.14159"/>`或直接使用`${3.14159/2}`。

### 14.5.3 在launch文件中使用xacro

需要将xacro文件转换为URDF后再给`robot_state_publisher`。可以在launch文件中使用`xacro`命令行工具，或使用Python的`xacro`模块。

修改launch文件，支持xacro：

```python
from launch import LaunchDescription
from launch_ros.actions import Node
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from ament_index_python.packages import get_package_share_directory
import os
import xacro

def generate_launch_description():
    pkg_share = get_package_share_directory('my_robot_description')
    xacro_file = os.path.join(pkg_share, 'urdf', 'my_robot.xacro')
    doc = xacro.process_file(xacro_file)
    robot_description = doc.toprettyxml(indent='  ')
    
    return LaunchDescription([
        DeclareLaunchArgument('gui', default_value='true', description='Use joint_state_publisher_gui'),
        Node(
            package='robot_state_publisher',
            executable='robot_state_publisher',
            name='robot_state_publisher',
            output='screen',
            parameters=[{'robot_description': robot_description}]
        ),
        Node(
            package='joint_state_publisher_gui',
            executable='joint_state_publisher_gui',
            name='joint_state_publisher_gui',
            condition=LaunchConfiguration('gui')
        ),
        Node(
            package='rviz2',
            executable='rviz2',
            name='rviz2',
            output='screen'
        )
    ])
```

需要确保`xacro` Python模块可用（通常在`ros-${ROS_DISTRO}-xacro`包中）。

## 14.6 URDF与TF的关系

URDF定义了机器人各连杆之间的固定和运动学关系。`robot_state_publisher`节点会根据URDF中的关节定义以及接收到的关节角度，计算每个连杆相对于根连杆的位姿，并以`/tf`话题发布。这为机器人感知、导航、运动规划等提供了坐标系变换基础。

例如，`base_link`到`left_wheel`的变换，就是由关节角度决定的动态变换。如果机器人还配有传感器（如激光雷达），我们可以将传感器坐标系定义为相对于`base_link`的固定关节（类型为`fixed`），这样传感器的TF就会自动发布。

## 14.7 本章小结

URDF是ROS中描述机器人的标准格式，它通过连杆和关节构建机器人运动学树。本章学习了：

- URDF的基本语法（link, joint, origin, geometry等）
- 创建一个两轮差速机器人模型
- 可视化URDF模型
- 使用xacro简化模型描述
- URDF与TF的关系

URDF是机器人仿真、运动规划、视觉感知等模块的基础。掌握URDF，就能为机器人创建准确的数字模型，为后续开发铺平道路。
