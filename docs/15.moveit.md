# 15.MoveIt运动规划

在机器人学中，运动规划是实现自主操作的核心技术之一。无论是机械臂的抓取、移动机器人的导航，还是多自由度系统的轨迹生成，都需要一个强大且易用的运动规划框架。MoveIt 是 ROS 中最流行的运动规划库，它提供了一个完整的平台，集成了运动学、规划、控制、感知等模块。本章将介绍 MoveIt 2（基于 ROS 2 的版本）的基本概念、架构、配置方法，并通过 Python 接口实现机械臂的运动规划。

可参考moveit文档 https://moveit.picknik.ai/main/index.html

## 15.1 MoveIt 概述

MoveIt 是一个开源的运动规划框架，旨在为机器人提供灵活、可靠的运动规划解决方案。它的主要功能包括：

- **运动规划**：支持多种运动规划器（如 OMPL、CHOMP、STOMP），可生成无碰撞的运动轨迹。
- **运动学**：提供正向运动学（FK）和逆向运动学（IK）求解器，支持多种求解算法（如 KDL、TRAC-IK）。
- **碰撞检测**：使用柔性碰撞库（FCL）进行高效的碰撞检测，避免机器人与环境或自身碰撞。
- **规划场景**：维护机器人、障碍物、环境的三维表示，支持添加、移除物体。
- **可视化与交互**：与 RViz 深度集成，提供交互式规划、抓取、拾取放置等操作界面。
- **控制接口**：将规划出的轨迹发送给机器人控制器（如 `follow_joint_trajectory` 动作服务器）。
- **运动规划任务**：支持复杂任务如抓取、拾取放置、移动操作等。

MoveIt 最初为 ROS 1 开发，ROS 2 版本称为 MoveIt 2，其核心功能已移植到 ROS 2 中，并保持了 API 的连续性。

## 15.2 MoveIt 架构

MoveIt 的核心组件包括：

1. **MoveGroup 节点**：用户与 MoveIt 交互的主要接口。它提供运动规划、执行、查询等功能，并通过 ROS 2 动作服务器与机器人控制器通信。
2. **规划场景（Planning Scene）**：维护机器人状态、世界几何、障碍物等信息，并发布到 `/planning_scene` 话题。
3. **规划管道（Planning Pipeline）**：定义运动规划的处理流程，包括规划请求适配、规划器选择、轨迹优化等。
4. **运动规划器（Motion Planners）**：实际进行路径搜索的算法库，如 OMPL、STOMP 等。
5. **运动学求解器（Kinematics Solver）**：计算末端执行器的位姿对应的关节角度。
6. **机器人模型（Robot Model）**：通过 URDF 和 SRDF（Semantic Robot Description Format）描述机器人的运动学、碰撞属性、关节组等。

下图是 MoveIt 2 的简化架构图（读者可自行查找官方图片）：

```
[用户代码] --> [MoveGroup] --> [规划管道] --> [运动规划器]
                 |                    |
                 v                    v
            [规划场景] <-------- [碰撞检测]
                 |
                 v
            [控制器] --> [机器人]
```

## 15.3 安装 MoveIt 2

在 Ubuntu 22.04 和 ROS 2 Humble 下，可通过 apt 安装 MoveIt 2：

```bash
sudo apt update
sudo apt install ros-humble-moveit
```

如果希望获得完整的开发工具（如 MoveIt Setup Assistant），可以安装：

```bash
sudo apt install ros-humble-moveit ros-humble-moveit-setup-assistant
```

安装完成后，可以验证 MoveIt 是否可用：

```bash
ros2 pkg list | grep moveit
```

## 15.4 配置 MoveIt

MoveIt 需要机器人的 URDF 模型以及一个 SRDF 文件，后者定义了关节组、末端执行器、自碰撞矩阵等语义信息。通常使用 **MoveIt Setup Assistant** 来生成这些配置。

### 15.4.1 准备 URDF

首先，确保你有一个完整的 URDF（或 xacro）文件，包含机器人的所有连杆、关节以及必要的碰撞、惯性属性。我们将使用上一章创建的两轮差速机器人模型？但是两轮差速机器人不是机械臂，MoveIt 更常用于机械臂。为了演示，我们可以使用一个简单的六轴机械臂 URDF（例如 Panda 机械臂）。如果你没有现成的机械臂 URDF，可以从 MoveIt 示例包中获取。

为了方便，本章将使用一个简化版的六轴机械臂 URDF（请确保你有该文件，或者下载 Panda 机械臂的 URDF）。我们假设功能包名为 `my_arm_description`，其中包含 `urdf/my_arm.urdf`。

### 15.4.2 使用 MoveIt Setup Assistant

启动 Setup Assistant：

```bash
ros2 run moveit_setup_assistant moveit_setup_assistant
```

界面操作步骤如下：

1. **选择 URDF 文件**：点击 "Browse"，选择 `my_arm.urdf` 文件。加载后，系统会解析机器人结构。
2. **自碰撞矩阵**：点击 "Generate Collision Matrix"，自动计算默认的自碰撞排除对。
3. **定义关节组**：创建关节组，例如 `arm_group`，包含所有运动关节（通常是 revolute 或 prismatic 关节）。还可以创建末端执行器组（如 `gripper`）。
4. **定义末端执行器**：指定末端执行器的名称、父链接（如 `tool0`）和子链接（如 `gripper_base`）。
5. **定义预设位姿**：可以定义一些常用姿势，如 "home"、"ready" 等。
6. **生成配置文件**：选择输出目录（通常为 `my_arm_moveit_config`），点击 "Generate" 生成 SRDF 和启动文件。

生成的配置包包含以下重要文件：
- `config/`：`srdf`、`kinematics.yaml`、`joint_limits.yaml`、`ompl_planning.yaml` 等。
- `launch/`：演示启动文件（如 `demo.launch.py`），用于在 RViz 中测试 MoveIt。
- `moveit_config.yaml`：MoveIt 节点参数。

### 15.4.3 测试 MoveIt 配置

进入生成的配置包（例如 `my_arm_moveit_config`），编译并运行演示：

```bash
cd ~/ros2_ws
colcon build --packages-select my_arm_moveit_config
source install/setup.bash
ros2 launch my_arm_moveit_config demo.launch.py
```

如果一切正常，RViz 会启动，并显示机械臂模型。在 RViz 中，你可以使用交互式标记（Interactivity Marker）拖拽末端执行器，MoveIt 会自动规划并执行运动。

## 15.5 使用 MoveIt 的 Python 接口

MoveIt 提供 Python 接口 `moveit_commander`，允许用户在脚本中控制机器人。下面通过一个示例介绍如何编写 Python 节点，实现机械臂的运动规划。

### 15.5.1 创建 Python 节点

创建功能包 `my_arm_moveit_demo`，依赖于 `rclpy`、`moveit_ros_planning_interface` 和 `geometry_msgs`。

```bash
cd ~/ros2_ws/src
ros2 pkg create my_arm_moveit_demo --build-type ament_python --dependencies rclpy moveit_ros_planning_interface geometry_msgs
```

编写节点文件 `my_arm_moveit_demo/moveit_demo.py`：

```python
#!/usr/bin/env python3

import rclpy
from rclpy.node import Node
from moveit_commander import MoveGroupCommander, PlanningSceneInterface, RobotCommander
from moveit_commander import roscpp_initialize
import sys
import time

def main(args=None):
    rclpy.init(args=args)
    
    # 初始化 MoveIt 接口
    roscpp_initialize([])  # 通常需要调用，但有些版本可能不需要
    robot_commander = RobotCommander()
    scene = PlanningSceneInterface()
    group_name = "arm_group"  # 替换为你的关节组名
    move_group = MoveGroupCommander(group_name)
    
    # 设置规划参数
    move_group.set_planner_id("RRTConnect")  # 可选的规划器
    move_group.set_planning_time(5.0)       # 规划时间（秒）
    
    # 获取当前关节状态
    current_joint_values = move_group.get_current_joint_values()
    print("Current joint values:", current_joint_values)
    
    # 设置目标位置（关节空间）
    target_joint_values = [0.0, -1.0, 0.0, -1.5, 0.0, 1.0]  # 示例值
    move_group.set_joint_value_target(target_joint_values)
    
    # 规划并执行
    plan = move_group.plan()
    if plan:
        success = move_group.execute(plan, wait=True)
        if success:
            print("Motion executed successfully")
        else:
            print("Execution failed")
    else:
        print("Planning failed")
    
    # 也可以设置末端执行器的目标位姿
    target_pose = [0.5, 0.2, 0.6, 0.0, 0.0, 0.0, 1.0]  # (x, y, z, qx, qy, qz, qw)
    move_group.set_pose_target(target_pose)
    plan = move_group.plan()
    if plan:
        move_group.execute(plan, wait=True)
    
    # 在场景中添加障碍物
    from geometry_msgs.msg import Pose
    from shape_msgs.msg import SolidPrimitive
    box_pose = Pose()
    box_pose.position.x = 0.4
    box_pose.position.y = 0.0
    box_pose.position.z = 0.4
    box_size = [0.2, 0.2, 0.2]  # 长方体尺寸
    scene.add_box("obstacle", box_pose, box_size)
    
    # 等待场景更新
    time.sleep(1.0)
    
    # 规划一个避开障碍物的轨迹
    move_group.set_pose_target(target_pose)  # 同上目标
    plan = move_group.plan()
    if plan:
        move_group.execute(plan, wait=True)
    
    # 移除障碍物
    scene.remove_world_object("obstacle")
    
    # 将机器人移动到预设姿势（如 home）
    move_group.set_named_target("home")
    plan = move_group.plan()
    if plan:
        move_group.execute(plan, wait=True)
    
    rclpy.shutdown()

if __name__ == "__main__":
    main()
```

### 15.5.2 配置与运行

在 `setup.py` 中添加入口点：

```python
    entry_points={
        'console_scripts': [
            'moveit_demo = my_arm_moveit_demo.moveit_demo:main',
        ],
    },
```

编译并运行：

```bash
cd ~/ros2_ws
colcon build --packages-select my_arm_moveit_demo
source install/setup.bash
ros2 run my_arm_moveit_demo moveit_demo
```

确保 MoveIt 的 `demo.launch.py` 已经在后台运行（或启动机器人状态发布器）。为了简化测试，我们可以先启动 MoveIt 演示（包含虚拟控制器），再运行脚本。

```bash
# 终端1：启动 MoveIt 演示（包含 robot_state_publisher 和控制器）
ros2 launch my_arm_moveit_config demo.launch.py

# 终端2：运行脚本
ros2 run my_arm_moveit_demo moveit_demo
```

观察机械臂运动，并在 RViz 中看到规划的轨迹和避障效果。

## 15.6 高级话题

### 15.6.1 运动规划器配置

MoveIt 支持多种规划器，主要在 `ompl_planning.yaml` 中配置。你可以为不同的关节组选择不同的规划器，设置规划时间、采样策略等。

### 15.6.2 运动学求解器

默认使用 KDL 作为运动学求解器，也可以配置 TRAC-IK 或自定义求解器。在 `kinematics.yaml` 中指定。

### 15.6.3 规划场景与物体操作

MoveIt 提供 `PlanningSceneInterface` 用于动态添加、移除障碍物，也可以从传感器数据（如点云）更新场景。这在抓取、避障等任务中非常重要。

### 15.6.4 抓取与拾取放置

MoveIt 内置了 `PickPlace` 规划器，可以自动生成抓取和放置的轨迹。需要定义抓取姿态、接近方向等参数。
